- **CBF** — REC Copa do Brasil 2026 (Anexo A, 126 clubes); notícia participantes/estreantes

- Wikipedia EN season / predefinições PT / sites oficiais *(Agente A — cruzamento parcial)*
- ogol — tabela edição *(não usar matéria de oitavas 2025)*

### Metodologia
1. Participantes = lista CBF (A∩B). DF = Capital + Ceilândia + Gama (não Brasiliense).
2. Confrontos oitavas = ge 22/06 (ida/volta + quem decide em casa); pares ge 26/05 como referência de chave.
3. Elenco dos 16 = plantel Transfermarkt B; A só para nota de divergência/lacuna.
4. Eliminados: fase alcançada; elencos detalhados **não** inventados (amostra parcial opcional).
5. Formato: `- Pos | Jogador | #n` (`—` = número não listado no TM).
6. **Cola de força relativa (atributos de jogo):** ver `forca-relativa-cola.md` (mesmo diretório).
